# Secure Burn HarmonyOS Starter

This is a HarmonyOS/ArkTS starter skeleton.

Open this directory in DevEco Studio and wire the SDK configuration generated by your installed HarmonyOS SDK.

Security intent:

- Use HUKS for identity keys.
- Use HTTPS/WSS only.
- Do not store private keys in app preferences.
- Do not send plaintext to the server unless explicit test capture mode is enabled.

The current source files define the app page, HTTP API client, WebSocket client, and HUKS wrapper shape.
